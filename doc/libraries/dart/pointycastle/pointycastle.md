# pointycastle

**Language:** dart\
**Url:**
[https://pub.dev/packages/pointycastle](https://pub.dev/packages/pointycastle)

The goal of this library is to provide an API similar to BouncyCastle.

## Security

The library is relatively new and suffers from some significant vulnerabilities.
One example is a large timing leak in ECDSA, that leaks the private key.
